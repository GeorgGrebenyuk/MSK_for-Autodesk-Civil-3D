# Сборник русских систем координат для AutoCAD Civil 3D (MSK_for-Autodesk-Civil-3D)

## Описание:

Изначально (2019г) проект создавался для распространения конфигурационных файлов CSD, описывающих пользовательскую библиотеку систем координат для всех продуктов Autodesk (первоочередно, для AutoCAD Civil 3D, AutoCAD Map 3D, Autodesk Revit, Autodesk InfraWorks, Autodesk ReCap). К осени 2026 года акцент был смещён на публикацию в машиночитаемом виде параметров МСК для территорий пост-советского пространства, из которых генерируются представления для импорта в среду Autodesk и OSGeo PROJ (sql-файл).

**Важно!** Все определения МСК имеют трехбуквенный префикс государства (по ISO 3166-1 alpha-3, исключение СССР - USSR), в которых вводилась данная МСК. Это сделано для удобства сортировки определений, а также для четкого разграничения определений разных стран на данную местность (например, на Крым в составе Украины до 2014 года распространялась зона X СК63 и в то же время ещё действуют СК63 редакции СССР. Отличия СК в том, что украинская версия имеет ненулевую широту начала, а СССР - сдвиг на север на величину этого "градусного начала").

Для автоматизации генерации определений см. инструменты из пакета https://github.com/GeorgGrebenyuk/MskCsGenerationUtils

Структура материалов репозитория:
```
- SourceData: папка с CSV-файлами, описывающими МСК, а также вспомогательными файлами для работы утилит генерации из MskCsGenerationUtils;
- OtherData: материалы определений, которые сохраняются в иных представлениях и подлежат переносу\пересчету в настоящую подборку;
```

## Состав определений

В основном, это системы координат городов и регионов России. Также имеются определения для регионов Беларуси, Украины, Казахстана, TODO - Абхазии, Армении, Азербайджана, Киргизии.

Для некоторых региональных СК в России имеются 2 варианта - старые от СК63/СК42 и новые на базе СК-95 (имеют в названии такой суффикс) - например, в Ставропольском крае, Владимирской области и пр.

## Добавление/использование:

С 2026 года определения распространяются в виде табличных данных, из которых генерируются представления в виде файлов для импорта в Autodesk Civil 3D (CSD-файлы, XML-словарь библиотеки СК) и для импорта в базу данных `proj.db` из поставки OSGeo PROJ (используется в QGIS и во вногих открытых ГИС-продуктах). Упомянутые представления доступны для загрузки из раздела [Releases](https://github.com/GeorgGrebenyuk/MSK_for-Autodesk-Civil-3D/releases).

**Важное примечание**: состав определений МСК в версии для OSGeo PROJ слегка урезан - там отсутствуют определения, которые были добавлены в поздних выпусках EPSG:

- ГСК-2011 - 16204-16209, 16210-16232, 16304-16331, 16907-16964, 17107-17133, 17134-17160;
- SK-1963, zone X (для Украины) - 7818, 7826, 7827, 7828, 7829, 7830;
- SK-1963, zone A (для Закавказья) - 2935, 2936, 2937, 2938;
- SK-1963, zone A (для Казахстана) - 2939-2941;

### Для развёртывания в среду Autodesk Civil 3D

Имеются 2 способа, первый автоматический, второй -- ручной.

#### Автоматическая установка

Запустите файл сценария `MskAutodeslInstall.bat`. В нём производится архивация имеющихся файлов в корне каталога `%LOCALAPPDATA%\Autodesk\User Geospatial Coordinate Systems` в отдельную папку в этом же каталоге, разархивирование архива из Releases в корень данной папки.

Вид размещенных файлов, гарантирующий корректную работу библиотеки представлен на ![скриншоте ниже:](/Docs/Screen/Root1.png)

**Примечание**: помимо конфигурационных файлов \*.csd в папке также могут присутствовать другие папки и данные (к примеру, архивы сборок координат)

#### Ручная установка

В случае, если у Вас уже имеется база СК и вы не хотите устанавливать данную, вы можете импортировать определения из XML-файла (словаря МСК) в вашу Библиотеку. Активируйте команду `MapCSLibraryImport` и выберите xml-файла из состава нужного Release. ### Для развёртывания в proj.db

Так как OSGeo PROJ активно развивается, и в proj.db меняется нумерация версий, пользователю предлагается самостоятельно импортировать пакет определений из SQL-файла в нужную БД proj.db (например, с помощью оконного приложения *DB Browser for SQLite*: File - Import - Database from SQL file.

# Дополнительная информация

## Объединение библиотек

В случае, если у вас есть необходимость добавить представленную библиотеку к вашей, рекомендуется изучить сведения [в данной статье](https://zen.yandex.ru/media/id/5d0dba97ecd5cf00afaf2938/pogrujaemsia-v-sistemy-koordinat-chast-4-avtomatizaciia-formirovaniia-biblioteki-sk-607707d2bfba535c1acb63d1). Логика работы будет строиться на формировании версии библиотеки в формате XML и её импорт (MAPCSLIBRARYIMPORT) к другой версии библиотеки (в чей состав вы хотите её включить). Этот же способ используется автором для публикации версии Ббилиотеки в xml-представлении

## Преобразование библиотеки в иное представление:

Начиная с версии Civil 3D 2018 (Map 3D 2018) появилась штатная возможность экспорта бибилиотеки координат через формат XML при помощи LSP-файла. Результирующий файл будет называться CSlibrary.xml и располагаться в папке "Документы" под профилем пользователя типа "C:\Users\User\Documents". Структура файла для экспорта определения системы координат МГГТ (Russia-MGGT) вместе со всеми связанными определениями представлена ниже:
```lisp
(command "MAPCSLIBRARYEXPORT"
"Russia-MGGT" "СистемаКоординат"
 " " "Да" "")
```
Все необходимые системы координат записываются построчно, функция "Да" отвечает за включение в итоговый XML-файл связанных определений (эллипсоидов/датумов).
Гибкий инструментарий по преобразованию библиотеки в иное представление (формат XML/WKT2) предоставляет пакет нодов Dynamo MapConnection, страница которого на GitHub приведена [по ссылке](https://github.com/TBS-Software/Dynamo.MapConnection) и справка [тут](https://inj9.gitbook.io/dynamo-mapconnection/)
