## 08.2026

Масштабное обновление всех определений. Удалите старые СК из чертежей перед использованием данных. Из массовых правок:
- замена всех символов `_` на `-` в названиях СК (старая проблема с неработоспособностью в IndraWorks систем координат, содержащих символ `_`);
- переименование всех префиксов `Russia` на `RUS` ради экономии 3 символов (актуально для МСК городов и районов);
- для группы СК от 63 префикс переопределен на `USSR`;
- для группы СК от 63 стандартизированы названия к виду `USSR-SK63-J6-Zone4`, третья часть названия - буквенный индекс зоны и цифра 3 или 6 (сколько градусов в зоне), четвертая часть - номер зоны;
- для группы СК от 63 добавлены районы Y, L, W, A, K;
- в описаниях СК переименованы примечания `grad` на `degree`;
- буквосочетание `Zona` переименовано в `Zone`, так корректнее с точки зрения термина;


Добавлены:

- зоны L для SK-63;
- ~150 шт. городских, местных, районах СК для территории России;
- 6 зон государственной, 27 проекций региональных СК для Украины (до 2014 года и территориальных изменений после);
- ... для республики Казахстан;
