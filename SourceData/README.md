# Исходные данные для генерации МСК

Для наглядности и удобства редактирования определений СК для РФ и близлежащих стран все параметры СК представлены в виде табличного текстового файла типа tsv (tab separated values) по следующей схеме (порядок строк соответствует столбцам файла), а также набора вспомогательных файлов:
- `AutodeskCSLibrary_Base.xml`: XML-файл словаря библиотек СК для Autodesk, содержит определения референц-эллипсоидов (датумов), эллипсоиды, геодезические преобразования. Определения СК генерируются на основе информации ниже;
## Для проекций типа "Поперечная Меркатора" aka Гаусса-Крюгера

**Примечание**: автор понимает разницу между проекциями типа "Поперечная Меркатора" и "Гаусса-Крюгера", но в civil 3D и OSGeo PROJ вторая есть частный случай первой (с масштабом = 1). Поэтому они объединены и здесь. Тем не менее вторая колонка `GK` может содержать метку `+`, что это именно проекция Гаусса-Крюгера;

Название файла `projectedCrsTransMercator.сsv`

Структура файла:
- `Name`: Краткое имя СК (на английском языке, без знака `_`, без иных знаков табуляции кроме тире `-`). 
- `GK`: Плюсик `+`, если тип проекции Гаусса-Крюгера;
- `Long`: Осевой меридиан, градусы (aka *Longitude of natural origin*);
- `Lat`: Широта начала, градусы (aka *Latitude of false origin*);
- `Scale`: Масштабный фактор, число (aka *Scaling factor for coord differences*);
- `FE`: Смещение на запад, метры (aka *False easting*);
- `FN`: Смещение на север, метры (aka *False northing*);
- `Bound_W`: Западная граница действия СК, градусы (в паре с `Bound_S` задает левый нижний угол действия СК);
- `Bound_E`: Восточная граница действия СК, градусы (в паре с `Bound_N` задает правый верхний угол действия СК);
- `Bound_S`: Южная граница действия СК, градусы (в паре с `Bound_W` задает левый нижний угол действия СК);
- `Bound_N`: Северная граница действия СК, градусы (в паре с `Bound_E` задает правый верхний угол действия СК);
- `Geod`: Номер EPSG геодезического преобразования aka `towgs84`;
- `DescrRU`: Описание СК (на русском языке);
- `DescrEN`: Описание СК (на английском языке);
- `Tags`: Тэги (`town`-городская, `region` - региональные, `ru` - российские, `by` - белорусские, `ua` - украинские, `ussr` - бывш. СССР и прочие внекатегорийные), может быть несколько;
- `Source`: Источник определения, ссылка;
- `Comment`: Комментарий при необходимости;

**Примечание**: из-за ограничений в Autodesk-библиотеке СК `Name` должно быть до 23 символов, описание `DescrEN` до 63 символов!

**Примечание:** поле `Geod` - это намеренное упрощение формулировки СК. В действительности проекция СК опирается на некоторую геодезическую СК, для которой задан датум, и в отдельности имеется одно или несколько геодезических преобразований между разными геодезическими СК. В нашем случае мы оставляем только 1 преобразование между двумя геодезическими СК (данной и WGS 84); по итогу у нас остаются переходы 1267 (SK 1963), 5044 (SK42 aka Pulkovo 1942), 5043 (SK95 aka Pulkovo 1995).

## Для проекций типа "Поперечная Меркатора" с аффинновой трансформацией

Встречается в:
- Autodesk-библиотеке, называется как "Поперечная Меркатора с последующей аффинновой обработкой";
- MapInfo, рассчитанная пользователями для опорных точек (параметры в файле MapInfo записываются в строгом порядке `A1, A2, A0, B1, B2, B0`);

Так как такого определения нет в OSGeo PROJ, то эти определения нужно будет пересчитать в классический формат (с помощью, например, конформного преобразования). TODO

- `Long`: (аналогично выше);
- `Lat`: (аналогично выше);
- `Scale`: (аналогично выше);
- `FE`: (аналогично выше);
- `FN`: (аналогично выше);
- `Bound_W`: (аналогично выше);
- `Bound_E`: (аналогично выше);
- `Bound_S`: (аналогично выше);
- `Bound_N`: (аналогично выше);
- `A0`: Аффинный параметр, число (aka Смещение по X / Сдвиг / Translation X);
